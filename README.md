# HIIGalaxies
A repository created to track progress and nuances related to my PhD research on HII Galaxies and the Hubble constant. 

I'm using [*STARLIGHT*](https://ui.adsabs.harvard.edu/abs/2011ascl.soft08006C/abstract), [*FADO*](https://ui.adsabs.harvard.edu/abs/2017A%26A...603A..63G/abstract), and [*CIGALE*](https://ui.adsabs.harvard.edu/abs/2020AAS...23522801B/abstract) to get a better understanding of the $L-\sigma$ [relation](https://ui.adsabs.harvard.edu/abs/2025MNRAS.538.1264C/abstract) of HII galaxies and the nature of starburst systems. I'm also using the $L-\sigma$ relation to get a precise estimation of $H_0$ and test some extensions of $\Lambda CDM$. I'm using [nested sampling](https://github.com/JohannesBuchner/MultiNest) to constrain cosmological parameters and dark energy models.

All scripts here run with data in the repository itself or with an external folder called DataHII where heavier files are stored. It is supposed that, if those files are too heavy, downloading scripts should be directed to the folder in order to reproduce calculations in any server with access to the repository.
